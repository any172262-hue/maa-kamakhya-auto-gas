## 3. Core Web Vitals Optimizations

### 1. Largest Contentful Paint (LCP)
- **Primary LCP Asset:** Official Brand Logo (`images/maa-kamakhya-auto-gas-logo.webp`).
- **Optimization Strategy:**
  - `<link rel="preload" as="image" href=".../maa-kamakhya-auto-gas-logo.webp" type="image/webp" fetchpriority="high" />` in `<head>`.
  - Inlined SVG fallback and WebP primary source via `<picture>` element.
  - Server pre-rendered HTML in `dist/` ensures critical text and DOM elements paint immediately before client-side hydration.

### 2. Cumulative Layout Shift (CLS)
- **Current Score Target:** **0.00**
- **Prevention Measures:**
  - All images declare explicit HTML `width` and `height` attributes alongside CSS `aspect-ratio`.
  - Dynamic content containers (calculator results, form validation alerts) reserve minimum vertical dimensions to prevent sudden DOM height expansions.
  - Web fonts load with `font-display: swap` using system fallback font metrics to minimize reflow during font swaps.

### 3. Interaction to Next Paint (INP)
- **Computational Overhead:** Minimal.
- **Calculator Logic:** `calculateFuelCosts()` executes synchronously in under 1 millisecond.
- **Debounced / Event Handlers:** Native range sliders and input events process with zero blocking tasks on the main JavaScript thread.

## 4. Asset Compression & Caching Strategy

1. **Modern Image Compression:**
   - WebP format utilized across all photographic and diagram assets.
   - Diagram infographic (`cng-installation.webp`) compressed and served with explicit dimensions.
2. **Font Optimization:**
   - Preconnect to `https://fonts.googleapis.com` and `https://fonts.gstatic.com` eliminates DNS lookup latency.
   - Preloaded stylesheet link initializes font downloading during HTML parsing.
3. **Static Caching:**
   - Hashed asset filenames (`assets/[name]-[hash].js`) enable immutable long-term caching (`Cache-Control: public, max-age=31536000, immutable`).
